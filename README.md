
# SpendWise — Personal Budget & Expense Tracker

## Project Overview

SpendWise is a beginner-friendly personal budget and expense tracker built using HTML and CSS. It helps demonstrate how to structure a webpage, create a form and table, use multimedia, and apply CSS styling.

This project combines Weeks 1, 2, and 3.

## Project Files

- `index.html` — Webpage structure and content.
- `style.css` — Colours, fonts, layout, form, table, and responsive styling.
- `README.md` — Project description and instructions.

## Week 1: HTML and CSS Foundation

- Semantic HTML elements.
- Main heading and introduction.
- Expense form.
- Linked CSS stylesheet.
- Element, class, and ID selectors.
- CSS box model basics.

## Week 2: Forms, Tables, and Multimedia

- Expense table with five sample records.
- Table header and body using `thead` and `tbody`.
- Category dropdown: Food, Transport, Rent, Entertainment, and Other.
- Labeled form inputs with IDs.
- Image with `src`, `alt`, and `width` attributes.
- Embedded video using `iframe`.
- Expandable help using `details` and `summary`.
- Advanced CSS selectors including `:hover`, `:focus`,
  `:nth-child(even)`, and `:not()`.

## Week 3: Styling and Visual Identity

- Navy, teal, white, and grey colour palette.
- Google Fonts: Manrope and DM Sans.
- Styled form inputs and button.
- Table borders, alternating rows, and hover effects.
- Cards, spacing, borders, and rounded corners.
- Responsive layout for smaller screens.
- CSS custom properties for consistent colours.

## How to Run

1. Keep `index.html`, `style.css`, and `README.md` in the same folder.
2. Open `index.html` in a web browser.
3. Use an internet connection for Google Fonts, the external images,
   and the embedded video.

## Current Limitations

This is a static HTML and CSS project. The table contains sample data.
The Add Expense button is intentionally a visual placeholder and does
not yet add or save new records. JavaScript can be added in a later
stage of the course.

Upload all three files to your existing SpendWise GitHub repository
